Install in under a minute

One small file. It sets the app up for your Windows account only.

1

Download

Click Download for Windows. You get Install-AltCodes.cmd. If your browser asks, choose Keep.

2

Double-click it

Open the file from your Downloads. A black window appears for a few seconds while it installs, then press any key to close it.

3

Start typing

A blue Alt icon appears in the tray (check under the ^ arrow). Try Alt + 130 in Notepad.

!
"Windows protected your PC"?

That's normal for small free apps that aren't sold through a store. Click More info, then Run anyway. The installer is plain text, so you can open it in Notepad and read every line first. Nothing else is downloaded.

If your browser won't let you save a .cmd file, download the zip instead, right-click it and choose Extract All, then double-click Install-AltCodes.cmd.

Handy codes

Hold Left Alt, type the number on the top row, release Alt. Click a tile to copy the character.

Codes with a leading 0 (like 0233) use the Windows character set; codes without it (like 130) use the old DOS set. Both work.

Questions

The short answers.

What does it actually do?

While you hold Left Alt, it turns the number-row keys into numpad keys. Windows then does what it always does with Alt codes. Nothing is recorded, stored or sent anywhere, and it has no network access at all.

Will it break my shortcuts?

  • Right Alt is never touched, so Alt + number shortcuts still work with it.
  • Ctrl + Alt (AltGr on AZERTY and other layouts) is left alone.

Start with Windows, or not

Right-click the tray icon and tick Run on startup. It's also listed in Task Manager → Startup apps. Right-click → Exit to close it; reopen it from the Start menu.

How do I remove it?

Download Uninstall-AltCodes.cmd and double-click it. It removes the app, the Start menu shortcut and the startup entry.

Doesn't work in one app?

Windows doesn't let normal apps send keys into programs running as administrator. Everywhere else it works. Some antivirus tools warn about new apps that read the keyboard; if yours does, allow %LOCALAPPDATA%\Programs\AltCodes.

Prefer PowerShell?

Paste this into PowerShell (no admin needed):

irm https://raw.githubusercontent.com/zubairmetabox/alt-codes/main/Install-AltCodes.ps1 -OutFile "$env:TEMP\Install-AltCodes.ps1"; powershell -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\Install-AltCodes.ps1"
